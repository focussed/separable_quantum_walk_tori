# Figures

Fidelity plots produced by `notebook/EXP033.ipynb`. They are regenerated on
each notebook run and are included here for reference only; the paper's own
figures are in `paper/`, alongside `main.tex`.

| File | What it shows |
|---|---|
| `demo_k2_new.png` | Fidelity for the new revival at k = 2, rho = 1/2, delta = pi/2, N = 6 |
| `demo_k4_new.png` | Fidelity for the new revival at k = 4, rho = 1/2, delta = pi/2, N = 6 |
| `demo_k4_dukes.png` | Fidelity for the Dukes revival at k = 4, rho = 3/4, delta = 0, N = 6 |
| `demo_k3_dukes.png` | Fidelity for the Dukes revival at k = 3, rho = 2/3, delta = 0, N = 8 |

Each plot marks the revival step with a vertical line and annotates the
period. The fidelity is `|<psi_0|psi_N>|^2`; it reaches 1 exactly at a
full-state revival.
